# Task: T4 — Daily backups to Cloud Storage + restore check

**Status:** done
**Written by:** Claude · **Date:** 2026-11-17 · **Plan:** `docs/plans/TRD.md` § T4

## Goal
Sync copies mistakes to every device, and history (IDX trace, arena, analyst, snapshots) can never be
rebuilt. Write one private backup file per day to a Cloud Storage bucket, and give a script that proves
a backup file can be restored (into memory only). The feature is **off** unless the env var
`GCS_BACKUP_BUCKET` is set, so this task changes nothing live until the owner creates the bucket.

## What to back up (verify each exists in code before listing it)
- Single keys: `sync:data`, `push:subs`, `alerts:history`, `alerts:state`, `jobs:state`,
  `fundarena:state`, `staples:data`
- Prefixes: `analysis:`, `arena:`, `brief:`, `forward:`, `idxtrace:`, `sentcalls:`, `snap:`, `staples:detail:`
- Not backed up (refetchable caches): `xs:`, `screener:`, `macro:`, `sbn:`, `calendar:`, `pink:`, `tick:last`.
Copy each value **exactly as stored** (`store.get`), including packed/gzip values; do not unpack.
Keys come from `store.keys(prefix)`, which is paginated since T2.

## Design
- `src/utils/backup.ts`: `BACKUP_KEYS`, `BACKUP_PREFIXES`, `buildBackup(entries, createdAt)` →
  `{ version: 1, createdAt, manifest: [{ key, sha256, bytes }], data: { key: value } }` (sha256 of the
  JSON of each value, via `node:crypto`), and `verifyBackup(file)` → `{ ok, keys, mismatches }`.
- `server/backup.ts` `backupStep(store, until)`:
  - returns `'off'` when `GCS_BACKUP_BUCKET` is unset; `'done today'` when `backup:last` (new store key,
    allowed) already holds today's WIB date; `'waiting'` before 02:00 WIB.
  - otherwise reads the keys (stop and return `'no time left'` if `until` is reached), gzips the JSON
    (`node:zlib`), uploads `backups/daily/YYYY-MM-DD.json.gz`, and on Sundays (WIB) also
    `backups/weekly/YYYY-MM-DD.json.gz`. Upload: GCS JSON API
    `POST https://storage.googleapis.com/upload/storage/v1/b/<bucket>/o?uploadType=media&name=<name>`
    with an access token from the metadata server
    (`http://metadata.google.internal/computeMetadata/v1/instance/service-accounts/default/token`,
    header `Metadata-Flavor: Google`). No npm dependency.
  - on success saves `backup:last` = `{ date, keys, bytes }` and returns a short summary;
    on error returns `failed: <message ≤120 chars>`. **Never log or return values.**
- `scripts/restore-backup.mjs <file.json.gz>`: gunzip, `verifyBackup`, print per-prefix key counts and
  OK/mismatch only — never values. It does not write to any database.
