# AssetRadar — Instruksi Proyek untuk Claude Code

> **Mulai sesi baru: baca `docs/BLUEPRINT.md` dulu** (hosting GitHub + Vercel + Supabase tanpa server selalu-menyala, secrets, database, jadwal, MCP). Cari kode lewat MCP codebase-memory (proyek `D-Asset-Radar-assetradar`), jangan baca `server.ts` utuh.

Aplikasi web pribadi (non-komersial) untuk memantau 147 aset (117 aset inti + 30 crypto tambahan dari 50 crypto terbesar; saham terbesar dunia & Indonesia, crypto, komoditas, indeks, kurs) secara real-time, dengan grafik bergaya TradingView, analisis sentimen berita, dan materi edukasi profil risiko. Bisa dipakai di PC dan HP (target: PWA). Pemilik: Dilan (Indonesia). **Kode, komentar, nilai internal, dan keterangan di awal setiap file dalam Bahasa Inggris.** **UI dua bahasa (tahap 4, 20 Okt 2026): Inggris = bahasa sumber, Indonesia = terjemahan.** Semua teks UI (termasuk aria-label, title, pesan galat, disclaimer, nama grup/aset umum) lewat `src/i18n/`: kunci baru ditambahkan ke `en.ts` **dan** `id.ts` (test paritas), komponen memakai `useT()`/`t()` (teks berformat: `<Rich>` untuk `**tebal**`), nama aset lewat `assetName()`/`groupTitle()`. Teks yang dibuat server/modul murni: kirim teks Inggris + kunci (`TextPart[]`, `src/i18n/textParts.ts`, dirender klien dengan `renderParts`) atau terima `?lang=en|id` (ringkasan Gemini di-cache per bahasa). Kode perintah Terminal tetap Inggris. `node scripts/check-i18n.mjs` harus 0. Format angka mengikuti bahasa (`id-ID`: `Rp1.234.567`, `1,25%`) kecuali Settings → "always en-US"; semua lewat `format.ts`. Setiap file baru wajib diawali komentar keterangan singkat berbahasa Inggris. **Berita tidak diterjemahkan**: judul tampil dalam bahasa asli artikelnya (server mengambil Google News edisi Indonesia `newsQueryId` + edisi Inggris `newsQuery`, lalu menggabungkan). Balas pemilik tetap dalam Bahasa Indonesia yang sederhana (bukan programmer profesional).

Awalnya dibangun di Google AI Studio (Build mode, Gemini), lalu dilanjutkan di sini. Spesifikasi asli: `docs/AssetRadar_SPEC.md`. Daftar prompt lanjutan asli: `docs/PROMPT_Lanjutan_AssetRadar.md` (Prompt 2–6 = sisa pekerjaan di bawah).

## Menjalankan

```bash
npm install          # .npmrc sudah set legacy-peer-deps (ada konflik peer vite 8 vs plugin-react)
npm run dev          # tsx server.ts → http://localhost:3000 (Express + Vite middleware)
npm run lint         # tsc --noEmit
npm test             # node --test src/**/*.test.ts server/*.test.ts (Node ≥ 22, impor .ts langsung)
node scripts/check-i18n.mjs   # teks UI yang tidak lewat i18n — harus 0
npm run build        # vite build → dist/ ; produksi: NODE_ENV=production npm start
```

Env (`.env`, lihat `.env.example`): `GEMINI_API_KEY` (opsional; tanpa ini sentimen tetap jalan versi non-AI). `GOLD_API_KEY` opsional dan tidak wajib (emas default dari gold-api.com tanpa kunci). `FINNHUB_API_KEY` opsional (trade real-time saham AS lewat WebSocket Finnhub; hanya di server — jangan pernah menampilkan, mencetak ke log, menyalin, atau mengirim nilainya ke browser). `BPS_API_KEY` opsional (gratis, webapi.bps.go.id, App ID dari akun BPS; inflasi inti/administered/volatile food di `#/macro` dibaca dari **tabel statis 908** (m-to-m sejak 2009, y/y dihitung `src/utils/bpsInflation.ts`) — pencarian variabel dinamis BPS tidak menemukannya; sama: hanya server, tidak pernah di-log; terpasang di Vercel 22 Okt 2026). Binance: **hanya data pasar publik**, tanpa kunci/akun/order. Jangan pernah menulis kunci API ke kode atau commit `.env`. Kunci opsional tahap 3 (semua fitur tetap jalan tanpa kunci, versi lokal): `SUPABASE_URL` + `SUPABASE_SERVICE_ROLE_KEY` (database sinkronisasi), `SYNC_PASSPHRASE` (login pemilik, ≥8 karakter) + `SYNC_SESSION_SECRET` (opsional), `CRON_TOKEN` (`POST /api/cron/daily`), `VAPID_PUBLIC_KEY`/`VAPID_PRIVATE_KEY`/`VAPID_SUBJECT` (web push), `TELEGRAM_BOT_TOKEN`/`TELEGRAM_CHAT_ID` (ringkasan pagi), `SYNC_DEV_MEMORY_DB=1` hanya untuk mencoba sync lokal tanpa DB. Langkah pasang di README "Optional setup (stage 3)".

Setelah setiap perubahan: `npm run lint && npm test && npm run build` harus lulus (dan `check-i18n` = 0).

**"status check"** (pemilik mengetik ini): jalankan skill `.claude/skills/status-check` → `node scripts/status-check.mjs` (laporan kesehatan aplikasi live: server, jaringan/sumber data, kesegaran data, tugas otomatis, fitur opsional), lalu ringkas dalam Bahasa Indonesia sederhana.

Ringkasan: Gemini bila ada kunci, jika tidak rule-based. Logika di `src/ai/`: `indicators.ts` (13 fitur tanpa look-ahead), `events.ts` (jadwal FOMC 2021–2026; hasil tercatat s.d. 2025, setelahnya **diinfer** dari pergerakan T-bill ±0,15 poin; event study), `model.ts` (regresi logistik, walk-forward, pemilihan strategi model/trend/mean-reversion di 60% awal OOS, dinilai di 40% holdout), `outlook.ts` (`buildAssetOutlook`, `rankOutlooks` + `RISK_PROFILES`, dipakai server & klien). Verdict: dua uji bisa membuktikan edge — strategi backtest (holdout) dan lean scorecard teknikal di riwayat aset (≥ 3 poin di atas base rate, ≥ 60 hari); skor bukti hanya bisa memveto/menggeser ±3 poin; tiap kartu punya `checks` (daftar lulus/gagal). ## Aturan wajib
- Nilai internal sudah berbahasa Inggris: grup `commodity | crypto | idStock | usStock | globalStock | index | forex`, status `live | delayed | error`, label sentimen `Bullish | Neutral | Bearish`, tab `risk`/`settings`, id aset IHSG = `jci`. Teks UI baru selalu lewat sistem terjemahan (`src/i18n/`, Inggris + Indonesia); manifest PWA tetap Inggris.

- Jangan pernah menampilkan angka contoh/dummy sebagai harga. Sumber gagal → "Data tidak tersedia" + tombol "Coba lagi".
- Grafik TradingView hanya lewat **widget resmi**; atribusi TradingView harus terlihat. Dilarang scraping/endpoint tidak resmi TradingView.
- Sentimen = ringkasan suasana berita, **bukan** sinyal beli/jual. Profil risiko = **edukasi**; tanpa proyeksi keuntungan. **Pengecualian (permintaan pemilik, 19 Okt 2026): AI Advisor (`#/advisor`) boleh menyarankan instrumen yang "favorable"**, tetapi hanya dari strategi yang terbukti di holdout out-of-sample (hit rate > base rate, ≥30 sinyal, return > rata-rata), selalu menampilkan hit rate vs base rate, dan disclaimer "statistical screen, not personal financial advice" wajib tetap ada. Jangan pernah menjanjikan keuntungan. Disclaimer wajib tetap ada (footer + Profil Risiko + AI Advisor).
- localStorage selalu dibungkus try/catch (pakai helper di `storage.ts`).
- Responsif: HP 375px tanpa scroll horizontal; PC 1440px. Mode terang & gelap harus terbaca. Hormati `prefers-reduced-motion`.
