# AssetRadar — Instruksi Proyek untuk Claude Code

Aplikasi web pribadi (non-komersial) untuk memantau 117 aset (saham terbesar dunia & Indonesia, crypto, komoditas, indeks, kurs) secara real-time, dengan grafik bergaya TradingView, analisis sentimen berita, dan materi edukasi profil risiko. Bisa dipakai di PC dan HP (target: PWA). Pemilik: Dilan (Indonesia). **Seluruh teks antarmuka, nama aset, komentar kode, dan keterangan di awal setiap file dalam Bahasa Inggris** (diubah atas permintaan pemilik, 19 Okt 2026; format angka `en-US`: `Rp1,234,567`, `+1.25%`). Setiap file baru wajib diawali komentar keterangan singkat berbahasa Inggris. **Berita tidak diterjemahkan**: judul tampil dalam bahasa asli artikelnya (server mengambil Google News edisi Indonesia `newsQueryId` + edisi Inggris `newsQuery`, lalu menggabungkan). Balas pemilik tetap dalam Bahasa Indonesia yang sederhana (bukan programmer profesional).

Awalnya dibangun di Google AI Studio (Build mode, Gemini), lalu dilanjutkan di sini. Spesifikasi asli: `docs/AssetRadar_SPEC.md`. Daftar prompt lanjutan asli: `docs/PROMPT_Lanjutan_AssetRadar.md` (Prompt 2–6 = sisa pekerjaan di bawah).

## Menjalankan

```bash
npm install          # .npmrc sudah set legacy-peer-deps (ada konflik peer vite 8 vs plugin-react)
npm run dev          # tsx server.ts → http://localhost:3000 (Express + Vite middleware)
npm run lint         # tsc --noEmit
npm test             # node --test src/**/*.test.ts (Node ≥ 22, impor .ts langsung)
npm run build        # vite build → dist/ ; produksi: NODE_ENV=production npm start
```

Env (`.env`, lihat `.env.example`): `GEMINI_API_KEY` (opsional; tanpa ini sentimen tetap jalan versi non-AI). `GOLD_API_KEY` opsional dan tidak wajib (emas default dari gold-api.com tanpa kunci). Jangan pernah menulis kunci API ke kode atau commit `.env`.

Setelah setiap perubahan: `npm run lint && npm test && npm run build` harus lulus.

## Arsitektur

- **Stack**: React 19 + Vite 8 + Tailwind 4 (via `@tailwindcss/vite`), TypeScript, Express (`server.ts`), `lightweight-charts` v5, `recharts` v3 (Profil Risiko, Quant Lab), `lucide-react`, `@google/genai`. Test Node "strip-only": jangan pakai parameter properties di constructor TS.
- **server.ts** (satu file): cache in-memory + endpoint:
  - `GET /api/market/snapshot` — semua harga (Indodax, Yahoo IHSG & kurs, emas)
  - `GET /api/market/indodax` — fallback REST crypto (cache 6 dtk; sparkline 24j cache 5 mnt)
  - `GET /api/market/yahoo` — semua aset Yahoo (`YAHOO_ASSETS`, ±95 aset) lewat `getYahooTicks()` memakai **spark batch** (`fetchYahooSpark`, maks 20 simbol/permintaan, `2d/15m`); cache 15 dtk saat bursanya buka, 5 mnt saat tutup (`yahooCacheMs`); hanya simbol yang kedaluwarsa diambil; gagal → harga terakhir dipertahankan. Perubahan 7h/30h dari `getWeeklyChanges` (`1mo/1d`, cache 30 mnt), 1 jam dari titik 15-menit (`hourChange`, "—" saat pasar tutup). SAR/IDR = USD/IDR ÷ 3,75 (peg; Yahoo tidak punya SARIDR=X). `addMarketCaps`: market cap live = harga × `supply` (dikonversi ke USD; KRW/HKD via `KRW=X`/`HKD=X`), crypto dari CoinGecko `/coins/markets` (cache 2 mnt, juga 1h/7d/30d). Klien polling tiap **10 dtk**
  - `GET /api/market/gold` — spot XAU dari gold-api.com (cache 30 dtk), perubahan/sparkline dari Yahoo `GC=F` (futures)
  - **`GET /api/market/analysis?symbol=`** — analisis berbasis bukti (cache 2 mnt, dihapus saat ada berita baru): `src/ai/technical.ts` (scorecard 9 indikator, deteksi pola dari pivot, hit rate historis vs base rate), `fundamentals.ts` (Piotroski F-score, gross profitability, P/E, P/B dari Yahoo `ws/fundamentals-timeseries` tanpa kunci, cache 12 jam; saham saja), `newsDrivers.ts` (kategori event + arah per aset + bobot sumber/recency; judul yang hanya melaporkan harga berbobot rendah), `analysis.ts` (gabungan berbobot + penjelasan + referensi jurnal). Skor `/api/market/intelligence` kini dari sini; Gemini hanya menulis ringkasan. Aset tanpa `newsQuery` mendapat pencarian Google News on-demand (`ensureAssetNews`, 3 mnt).
  - **`GET /api/quant/factors?universe=usStock|idStock|index|forex|commodity|everywhere`** — Quant Lab: harga bulanan `1mo/max` (dibersihkan `despike`), portofolio value (reversal 5 tahun) & momentum (12-1) long-short rank-weighted (AMP 2013) dan long-only sepertiga teratas, filter F-score ≥ 8 (skor terbit + jeda 4 bulan), `^IRX` sebagai rf; cache 6 jam. Logika di `src/ai/factorPortfolio.ts`.
  - `GET /api/market/yields` — kurva imbal hasil AS (`^IRX`, `^FVX`, `^TNX`, `^TYX`), cache 60 dtk (panel CURV).
  - `GET /api/market/intelligence?symbol=` — sentimen (momentum harga + nada berita) + 6 berita terbaru aset itu dari hub berita; diperkaya Gemini `gemini-3.8-flash` di latar belakang (race 1,8 dtk, cache 5 mnt, **dihapus otomatis saat ada berita baru** untuk aset itu / MACRO / GEO)
  - `GET /api/market/history?symbol=<app symbol>&interval=<1|5|15|30|60|240|D|W>` — candle OHLC; crypto dari Indodax `tradingview/history_v2` (Yahoo tidak punya `BTC-IDR` dkk., 404), aset lain dari Yahoo (240 = agregasi 60m→4j); respons berisi `source`; hanya simbol di `ASSETS`
  - `GET /api/market/correlation` — matriks korelasi Pearson return harian 30 hari (BTC, ETH, JCI, SPX, NDX, N225, FTSE, GOLD, USD, EUR), cache 6 jam
  - **`GET /api/ai/outlook?horizon=20|60&profile=conservative|moderate|aggressive`** — AI Advisor (hanya aset `ai: true`, ±55 aset, `mapLimit` 6 paralel): riwayat harian ~5 tahun (Yahoo `1d/5y`; crypto Indodax `tf=1D` IDR) + `^IRX`, `^TNX`, `DX-Y.NYB`; harga live dipakai sebagai bar hari ini; hasil di-cache 10 mnt (riwayat 6 jam), hitung ulang di latar belakang, warm-up 3 dtk setelah server start (komputasi pertama ±16 dtk). Ringkasan: Gemini bila ada kunci, jika tidak rule-based. Logika di `src/ai/`: `indicators.ts` (13 fitur tanpa look-ahead), `events.ts` (jadwal FOMC 2021–2026; hasil tercatat s.d. 2025, setelahnya **diinfer** dari pergerakan T-bill ±0,15 poin; event study), `model.ts` (regresi logistik, walk-forward, pemilihan strategi model/trend/mean-reversion di 60% awal OOS, dinilai di 40% holdout), `outlook.ts` (`buildAssetOutlook`, `rankOutlooks` + `RISK_PROFILES`, dipakai server & klien). Verdict: dua uji bisa membuktikan edge — strategi backtest (holdout) dan lean scorecard teknikal di riwayat aset (≥ 3 poin di atas base rate, ≥ 60 hari); skor bukti hanya bisa memveto/menggeser ±3 poin; tiap kartu punya `checks` (daftar lulus/gagal). BI rate belum dimodelkan (tidak ada data historis gratis).
  - **Hub berita live** (`newsHub` di server.ts): RSS langsung (CoinDesk, Cointelegraph, CNBC Indonesia, ANTARA, FXStreet, BBC World, Al Jazeera) tiap 60 dtk + Google News per aset (edisi ID & EN, `when:1d`) tiap 2 mnt + pencarian konflik Google News (hanya alert "high"); polling hanya saat ada penonton (≤5 mnt sejak permintaan terakhir). Judul ditandai aset lewat `src/utils/newsTags.ts` (`tagHeadline`, `MACRO`, `GEO` + `detectGeoAlert`: "high" = perang baru/eskalasi besar → banner merah, "elevated" = serangan oleh aktor besar). `GET /api/market/news-feed` (60 terbaru) dan **`GET /api/market/news-stream` (SSE: `snapshot`, `news`, `ping` 20 dtk)**. Klien: `src/services/newsStream.ts` (satu EventSource bersama, cadangan polling 60 dtk bila stream macet), hook `src/hooks/useLiveNews.ts`, komponen `NewsTape` (pita berita), `GeoAlertBanner` (semua halaman, bisa ditutup, notifikasi desktop).
- **Klien**:
  - `src/services/marketDataService.ts` — `MarketDataManager`: WebSocket Indodax (`market:summary-24h`, token publik resmi dari dokumentasi Indodax; `PAIR_MAP` dari semua aset ber-`indodaxPair`), backoff, putus saat tab tersembunyi, polling REST Indodax **hanya saat WS putus**, polling Yahoo 10 dtk, emas 30 dtk, status `live | reconnecting | delayed | offline`, snapshot harga terakhir di localStorage (tick bertanda `fromSnapshot`). Helper: `fetchAssetIntelligence`, `fetchAssetAnalysis`, `fetchHistory`, `fetchCorrelation`, `fetchNewsFeed`, `fetchAiOutlook`, `fetchQuantFactors`, `fetchYieldCurve`. App.tsx mengisi `liveHistory` (`src/utils/movers.ts`, buffer 20 mnt) di setiap update harga → "Live 5m" movers & kolom %5M Terminal.
  - `src/config/assets.ts` — tipe (`PriceTick`, `OhlcCandle`, `CorrelationMatrix`, `MarketNewsItem`, `ExchangeId`, dll.), daftar `ASSETS` (**117 aset**, grup `commodity | crypto | idStock | usStock | globalStock | index | forex`; dibuat dengan factory `crypto()`, `idStock()`, `usStock()`, `worldStock()`, `commodity()`, `globalIndex()`, `rupiahPair()`; tiap aset punya `code` unik = kode Terminal & tag berita, `aliases`, `keywords` (untuk tag berita & pencarian — hindari kata umum seperti "intel", "amazon"), `supply` (jumlah saham/pasokan untuk market cap), `quick` (tombol Quick Chart), `ai` (ikut AI Advisor)), `getAssetByCode`, `searchAssets`, `TIMEFRAME_OPTIONS`. CPO (`CPO=F`) dan batu bara tidak tersedia gratis → tidak dicantumkan. Simbol widget TVC:* (N225, HSI, STI, DXY) tidak bisa di-embed → `tvWidgetUnsupported`, selalu grafik alternatif; XETR:DAX hanya D/W → `usesBackupChartFallback`. CNY/IDR di Yahoo hanya punya harga hari ini (tanpa riwayat).
  - `src/utils/` — `format.ts` (Rupiah/persen en-US), `marketHours.ts` (jam BEI 09:00–16:00 WIB), `sentiment.ts` (kata kunci kata-utuh, parser RSS), `storage.ts` (semua localStorage via try/catch: tema, timeframe, watchlist, snapshot harga, start-in-terminal, hasil profil risiko), `router.ts` (hash routing `#/radar`, `#/asset/<id>`, `#/watchlist`, `#/risk`, `#/settings`, `#/terminal`; hash lama Indonesia tetap diterima), `correlation.ts`, `candles.ts`. Semua punya test `*.test.ts`.
  - `src/App.tsx` — state utama, tema, routing hash, layout (sidebar PC / bottom nav HP), footer disclaimer.
  - `src/components/` — `RadarView` (pencarian `AssetSearch`, Quick Chart, `MoversPanel`, Top 20 market cap & tabel per grup via `MarketTable`, sentimen dengan kotak pencarian), `AssetDetailView` (harga, timeframe, chart, `AssetIntelligencePanel` + `AssetAnalysisPanel`), `QuantSimView` (`#/quant`), `AdvisorView`, sidebar bisa diciutkan (`getSidebarCollapsed`), `WatchlistView`, `RiskProfileView` (kuesioner + hasil, lazy-load karena `recharts`), `SettingsView`, `Navigation`, `SparklineChart`, `RadarLogo`.
- **Gaya**: token warna CSS di `src/index.css` (`--bg-canvas`, `--bg-surface`, `--accent-radar`, `--color-up/down/gold`, dll., terang & gelap via `data-theme`). Font: Plus Jakarta Sans + JetBrains Mono (`.font-mono-num`). Komponen memakai inline `style={{...var(--...)}}` + kelas Tailwind — ikuti pola ini.

## Aturan wajib
- Nilai internal sudah berbahasa Inggris: grup `commodity | crypto | idStock | usStock | globalStock | index | forex`, status `live | delayed | error`, label sentimen `Bullish | Neutral | Bearish`, tab `risk`/`settings`, id aset IHSG = `jci`. Teks UI baru (termasuk Profil Risiko & PWA) ditulis dalam Bahasa Inggris.

- Jangan pernah menampilkan angka contoh/dummy sebagai harga. Sumber gagal → "Data tidak tersedia" + tombol "Coba lagi".
- Grafik TradingView hanya lewat **widget resmi**; atribusi TradingView harus terlihat. Dilarang scraping/endpoint tidak resmi TradingView.
- Sentimen = ringkasan suasana berita, **bukan** sinyal beli/jual. Profil risiko = **edukasi**; tanpa proyeksi keuntungan. **Pengecualian (permintaan pemilik, 19 Okt 2026): AI Advisor (`#/advisor`) boleh menyarankan instrumen yang "favorable"**, tetapi hanya dari strategi yang terbukti di holdout out-of-sample (hit rate > base rate, ≥30 sinyal, return > rata-rata), selalu menampilkan hit rate vs base rate, dan disclaimer "statistical screen, not personal financial advice" wajib tetap ada. Jangan pernah menjanjikan keuntungan. Disclaimer wajib tetap ada (footer + Profil Risiko + AI Advisor).
- localStorage selalu dibungkus try/catch (pakai helper di `storage.ts`).
- Responsif: HP 375px tanpa scroll horizontal; PC 1440px. Mode terang & gelap harus terbaca. Hormati `prefers-reduced-motion`.
